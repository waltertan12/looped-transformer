# Arithmetic grid: unique blocks × loops

Source: `results/toy/grid`, 12 runs (12 finished). Generated by `scripts/arith_report.py`.

Every model has 1 prelude block + *core* blocks run *loops* times + 1 coda block, width 256. Trained on depths 1–8 with a curriculum (add a depth at 90% exact match on the current top depth); tested on held-out problems at depths 1–16. Accuracy = exact match on the whole answer (chance ≈ 0). Effective depth = core × loops.
